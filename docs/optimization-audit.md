# FreePath 优化与功能补全建议

## 一、优先级 P0（建议先做）

1. **把占位 API 变成可用 API**
   - `app/api/projection/route.ts` 与 `app/api/records/route.ts` 仍是占位逻辑，当前核心数据流仅依赖 `localStorage`。
   - 建议补齐：参数校验、持久化（Prisma + PostgreSQL）、错误码、鉴权。

2. **输入校验与边界处理**
   - 当前参数表单会把非数字输入直接转成 `0`，容易造成误导性结果。
   - 建议补齐：最小值/最大值、必填校验、异常提示（例如安全提取率 <= 0、负数本金、空日期）。

3. **性能优化（计算层）**
   - `generateProjectionSeries` 内部按月调用 `calculateAssetAtMonth`，会形成 O(n²) 计算。
   - 建议改为单次循环递推，得到 O(n) 并减少渲染卡顿风险。

## 二、优先级 P1（体验明显提升）

1. **记录页能力升级**
   - 增加按月份去重/覆盖、编辑记录、批量导入导出（CSV）。
   - 增加“累计投入 vs 当前资产”的回放图，直观看趋势。

2. **计划页/分析页参数联动**
   - 目前页面内置固定示例参数。
   - 建议读取首页统一参数，并支持“一键应用当前配置”，避免多页面口径不一致。

3. **图表可读性增强**
   - 当前是轻量条形展示。
   - 可增加：hover tooltip、关键节点标注（达标月份）、按年/按月切换。

## 三、优先级 P2（产品化）

1. **多目标规划**
   - 除“退出全职”外，支持“应急金/教育金/买房首付”等目标并行。

2. **风险与敏感性分析**
   - 支持收益率区间、通胀、支出波动、Monte Carlo 区间展示（P10/P50/P90）。

3. **账户体系与云同步**
   - 设置页已预留方向，建议补齐登录、设备同步、历史版本。

## 四、工程质量建议

1. **测试体系**
   - 为 `lib/finance.ts` 与 `lib/date.ts` 补充单元测试，覆盖极端输入。

2. **可观察性**
   - 增加基础埋点：关键参数修改、方案切换、目标达成率变化。

3. **文档完善**
   - README 目前仍是模板，建议补齐产品说明、运行方式、数据边界、路线图。
